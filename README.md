# E-Commerce Customer & Transaction Analytics

## Objective
Analyze customer transactions to understand revenue, customer value, product performance, retention, and purchasing behavior.

## Stack
- MySQL
- Python
- Pandas / NumPy / Matplotlib
- Power BI

## Dataset
- 5,000 customers
- 150 products
- 50,000 orders
- 75,000 order-line items

## Analysis
1. Revenue and order trends
2. Category and product performance
3. Customer revenue and AOV
4. Repeat purchase behavior
5. RFM segmentation
6. Retention/cohort analysis
7. City and payment-method analysis
8. Cancellation and return rates

## Files
- data/: generated CSV files
- sql/database_schema.sql: MySQL schema
- sql/data_analysis.sql: analysis queries
- python_analysis.py: Python analysis and RFM segmentation

## Power BI
Create three pages:
1. Executive Overview
2. Customer Analytics
3. Retention & RFM

## Important
The dataset is synthetic and created for portfolio/interview practice.
